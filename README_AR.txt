SILA | صِلَة — مشروع أندرويد مبني من ملف HTML الذي أرسلته

المشروع يحتوي على:
- تطبيق Android بسيط يعرض index.html داخل WebView.
- دعم JavaScript وملفات الصور التي يختارها المستخدم.
- GitHub Actions لبناء APK تلقائيًا.
- لم يتم إنشاء مشروع Supabase جديد أو تعديل قاعدة البيانات.

مهم:
- هذا مصدر مشروع أندرويد، وليس APK جاهزًا بعد.
- إعداد Supabase الموجود داخل HTML بقي كما هو.
- لم يتم اختبار الاتصال الحي بقاعدة Supabase أو عمليات النشر والصفقات.
- مفتاح Supabase الظاهر في HTML هو publishable key، وليس secret/service-role key.

طريقة البناء:
1) أنشئ مستودعًا جديدًا على GitHub.
2) ارفع محتويات هذا المجلد إلى المستودع (لا ترفع مجلد SILA_Android_GitHub_Project كطبقة داخلية؛ ارفع الملفات الموجودة داخله).
3) افتح تبويب Actions.
4) اختر Build SILA APK ثم Run workflow، أو انتظر انتهاء البناء بعد رفع الملفات.
5) افتح نتيجة التشغيل الناجح، ثم Artifacts، وحمّل SILA-debug-APK.zip.
6) فك ضغطه لتحصل على app-debug.apk.

هذا APK تجريبي للتثبيت المباشر، وليس إصدارًا موقّعًا للنشر على Google Play.
